# Kriz UI Page

This pages serves as an example and documentation for my collection of reusable UI components [Kriz UI](https://github.com/kriztiam/kriz-ui).

## Installation

```
git clone https://github.com/kriztiam/kriz-ui-page
cd kriz-ui-page
npm install
npm run dev
```

## Built With

- React 19.2.0
- Next.js 15.5.4
- TypeScript 5.9.3
- Font Awesome Icons
- PostCSS + CSS Tools for styles
- ESLint, Prettier, and Stylelint for code quality
